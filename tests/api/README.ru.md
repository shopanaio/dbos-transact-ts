# Эталон API P0

`public-declarations.json` фиксирует публичные декларации DBOS, DBOSClient,
WorkflowQueue, Debouncer и DebouncerClient из существующей локальной сборки до P0.
Эталон не выводится из текущих типов при проверке и автоматически не обновляется.
Происхождение локальной сборки не подтверждалось новой сборкой; перед приёмкой
требуется сопоставить эталон с принятой версией fork.

`check-public-api.cjs` сравнивает декларации собранного SDK с эталоном.
Единственное разрешённое изменение — расширение `DBOSClient.create` для фабрики.
`consumer.ts` содержит примеры обоих способов конфигурации и проверяет
непрозрачность системной транзакции. CI запускает `npm run check:public-api`.
В рамках подготовки P0 сборка и проверки не запускались по указанию пользователя.
